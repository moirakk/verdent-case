## 项目背景

这是 Verdent 的独立、私有、云端社媒增长 OS。当前主要由一位负责人使用，但以后需要安全交接给新同事。它把原始资料、事实核实、六平台英文内容、海报/视频 Brief、素材、排期、发布 URL 和复盘放在同一个任务里。

所有对外文案必须是英文；内部界面、分析和状态说明可以使用中文。负责人手动复制并发布内容，系统目前不自动代发。

## 第二阶段：完成外部连接中心

在保留现有界面结构和 Verdent 深绿/荧光绿视觉的前提下，完成一个简洁的 Connections 页面或抽屉。

每个平台显示：

- 平台名称。
- 未配置、就绪、已连接、同步失败、使用缓存等状态。
- 上次成功同步时间和数据新鲜度。
- 最近两条官方内容的日期、链接、正文摘要和媒体类型。
- 所需配置项名称，只显示变量名，不显示真实值。
- 官方文档入口与费用/权限提示。
- 管理员可见的“同步”操作。

平台范围：

- X / Twitter
- Discord
- LinkedIn
- Reddit
- Instagram
- TikTok
- 飞书

连接设计要求：

- Secret 只能配置在服务端托管环境。
- 页面不能提供读取或回显 Secret 的 API。
- 刷新失败时保留上次成功数据，并明确标记为缓存及其时间。
- 不因为一个平台失败而阻塞其他平台。
- Reddit 无密钥模式可以先独立可用。
- 每个平台应有可测试的适配层，避免把所有平台逻辑继续堆在一个大文件。
- 增加超时、错误归一化、限流提示和最小必要日志。
- 不自动发布，不请求写权限，除非未来有明确新需求。

## 第三阶段：把最新内容接入生成系统

把已同步的每个平台最近两条 Verdent 官方内容注入现有 AI Prompt：

- 样本只用于 voice、format、opening、paragraph rhythm、CTA、emoji、hashtags 和 asset relationship。
- 样本不能作为当前 Brief 的事实来源。
- 当前 Brief、官方资料和确认状态始终优先。
- 每个平台必须输出 `Recent-post calibration`。
- 少于两条时必须输出 `VOICE SAMPLE MISSING`，不能伪造历史风格。
- 同步时间过旧时必须标注 stale。
- 必须保留当前静态基线作为连接不可用时的降级方案。
- 不要静默覆盖用户已经编辑的文案。

## 第四阶段：实现“粘贴链接 → 专业可视化分析”

负责人可以粘贴单条公开发布链接或网页链接。系统自动识别平台并尽量通过官方 API 或安全的公开页面信息读取：

- 作者/账号
- 发布时间
- 完整正文
- 链接
- 内容类型
- 图片/视频/文本类型
- 可见互动数据
- 采集时间

分析视图至少包含：

- 内容模式：release、model launch、builder story、editorial、service notice、partner/event。
- 开头结构和 Hook 类型。
- 字数、段落、CTA、Emoji、Hashtag。
- 媒体类型和素材关系。
- 如果数据可用，展示曝光、互动、互动率和同类内容对比。
- 平台之间可切换，另有综合预览。
- 明确区分“平台提供的数据”和“系统推断”。
- 不支持的数据字段显示不可用，不要估算。
- 只读取负责人主动粘贴或管理员授权的数据。
