# EP001 // Plan Mode

## Purpose

Show what Plan Mode does.

Skillbook is only the container. EP001 should not explain Skillbook as the main
topic. It should prove this transformation:

```text
Messy Ask -> Working Plan
```

## Core Message

A vague idea is not a plan.

Plan Mode turns unclear intent into a working production plan.

## Example Direction

The exact example is still being selected, but it should follow this shape:

```text
Input:
I have a vague idea, but I do not know what to make first.

Plan Mode:
breaks it into goals, sequence, outputs, checklist, and acceptance criteria.

Output:
a plan that can be executed today.
```

## Avoid

- PRD
- content-plan as the main artifact unless the example specifically needs it
- explaining "what Skillbook is" for the whole video
- meta language about how to show skills
- long paragraphs
- decorative UI that hides the actual transformation

## Working Line

```text
Messy idea in.
Working plan out.
```
