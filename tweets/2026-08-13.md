## 2. tphuang — 价格角度：Fable 5 级别性能，输出成本约低 57 倍

**Post**: https://x.com/tphuang
**Date**: 2026-08-12（V4 Pro 0813 发布当日讨论）

**内容介绍**：从价格/性能比切入的解读：V4-Pro 0813 相比 4 月 Preview 版，Terminal Bench 涨 15.8%，达到 Fable 5 级别的性能，而输出成本约低 57 倍（$0.87 vs $50 per 1M output）。模型 1.6T 参数、MIT 协议。

**核实说明**：来源 https://kingy.ai/blog/deepseek-v4-pro-0813-fable-5-price-fact-check 确认——输出 token 价差为 **57.5x**，输入 token 价差约 **23x**；总体成本比取决于具体 workload 的 token 结构（输入/输出配比）和缓存命中率，因此「57 倍」严格来说只成立于输出 token 这一项，不宜直接当作总账单倍数使用。

**为什么适合转**：这是本次发布最容易被工程团队实际拿去做决策的角度，而且「一个数量级以上的价差」比 benchmark 名次更能改变工作流设计（能不能重试、能不能跑并行 agent）。转的时候把「输出 token 价差 57x / 输入约 23x」的边界说清楚，反而更显专业。

### Verdent Repost Options

> **Option A**: $0.87 vs $50 per 1M output tokens. Once the gap is 57x on output, the question stops being "which model is better" and becomes "how many attempts can I afford." Retry budgets, parallel agents, and self-verification loops all get cheaper to design. Caveat: input is ~23x, so your real ratio depends on token mix.

- 中文：每百万输出 token，$0.87 对 $50。当输出端价差到 57 倍，问题就不再是「哪个模型更好」，而是「我能跑几次」。重试预算、并行 agent、自校验循环的设计成本全都下来了。注意：输入端约 23 倍，所以你的真实比例取决于 token 结构。

> **Option B**: The interesting number in the V4 Pro 0813 release isn't a benchmark, it's a price ratio. Frontier-adjacent agent performance at roughly 1/57th the output cost changes what you're willing to spend tokens on — verification passes you'd previously skip suddenly pencil out.

- 中文：V4 Pro 0813 发布里最有意思的数字不是 benchmark，是价格比。接近前沿的 agent 表现，输出成本约为 1/57，这会改变你愿意把 token 花在哪儿——以前会跳过的校验环节，现在算得过账了。
