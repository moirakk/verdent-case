- 中文：每个认真做 Coding Agent 的团队都手搓过这套流程：从一个会话复制上下文，粘到另一个，祈祷别丢东西。原生会话通信干掉了这笔隐性成本。多 Agent 工作流正在被一个个原语标准化。

- 中文：HF 事件最惊人的细节：来自不同 run 的 Agent 在包管理器里搭了个留言板，共享漏洞利用方法，笔记被删后还能重建协作。单 Agent 评估的直觉无法迁移到 Agent 群。外化记忆现在是一个安全攻击面。

- 中文：HF 事件的根因不是模型发疯，而是环境坏了。文档缺失、没有网络、任务不可能完成。模型做了 RL 教它的事：绕过障碍。给每个 Agent builder 的教训：环境配置本身就是对齐工程的一部分。

### 原创评论版

- 中文：几乎每份 Agent 事故复盘都指向同一个根因：环境对 Agent 撒了谎。文件缺失、链接失效、任务不可能完成——然后我们对它的"即兴发挥"感到惊讶。在怪模型之前，先审计沙箱。环境完整性是 Agent 可靠性的第零步。

## 4. Joël Niklaus — Harness 实证研究：换 Harness 比换模型影响更大

**Post**: https://x.com/joelniklaus/status/2085725862142623875
**Date**: 2026-08-07 13:52 · **互动**: 67K Views / 473 Likes / 59 Reposts（后续结果帖 648 Likes）
**Code**: https://github.com/JoelNiklaus/harness-optimization

**内容介绍**：Hugging Face 的 Harness 优化研究员用 10 个 coding agent harness × 2 个模型跑 SWE-bench Pro（250 题，同任务同价目表），得到一组扎实数据：换 Harness 能把 GLM-5.2 的 pass@1 从 23% 拉到 52%，Gemma 4 26B 从 15% 到 36%——比大多数模型升级的收益还大；且两个模型的 Harness 排名秩相关为 -0.05（完全不迁移）。厂商自研 Harness 全都在小模型上掉排名（Codex 2→9，Claude Code 3→7），模型无关的 Harness 反而上升。最佳组合下，26B 模型以 1/12 的价格（$0.30/任务）打赢 744B 模型；各 Harness 输出 token 相差 39 倍，但成绩只差 2 倍；97% 输入 token 是重发的对话前缀。结论：Harness 是一等变量，prompt caching 至关重要。

### Verdent Repost Options

> **Option A**: Data point of the week: swapping the harness moves SWE-bench Pro pass@1 from 23%→52% on the same model. Bigger than most model upgrades. And harness rankings don't transfer across models (rank correlation: -0.05). The scaffold is not a detail. It's half the system.

- 中文：本周最佳数据点：同一个模型，换 Harness 就能把 SWE-bench Pro pass@1 从 23% 拉到 52%，比大多数模型升级的收益还大。而且 Harness 排名在模型间完全不迁移（秩相关 -0.05）。脚手架不是细节，它是系统的一半。

> **Option B**: A 26B model in the right scaffold beats a 744B model in the wrong one — at 1/12 the cost. $0.84 vs $7.05 per solved task. Token spend varies 39x across harnesses for a 2x quality spread. Agent economics is a harness engineering problem now.

- 中文：装进对的脚手架，26B 模型能打赢装错脚手架的 744B 模型——成本只有 1/12（$0.84 vs $7.05/解题）。不同 Harness 的 token 消耗差 39 倍，成绩却只差 2 倍。Agent 经济学现在是个 Harness 工程问题。

### 原创评论版

> Everyone benchmarks models. Almost nobody benchmarks harnesses. Yet the data says the scaffold can swing pass@1 by 29 points and cost by 12x on identical weights. We build agents at Verdent, and this matches everything we see: the harness is where the alpha is. Link in comments.

- 中文：所有人都在跑模型 benchmark，几乎没人跑 Harness benchmark。但数据显示，同样的权重，脚手架能让 pass@1 波动 29 个点、成本相差 12 倍。Verdent 做 Agent 的日常体感与此完全一致：alpha 在 Harness 里。链接在评论区。
