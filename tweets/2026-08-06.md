## 1. Prime Intellect — Prime Agent：自改进 RLM 编程/长程 Agent 框架发布

**Post**: https://x.com/PrimeIntellect/status/2085086999267144083  
**Author Quote**: https://x.com/sethkarten/status/2085088711709249913  
**Date**: 2026-08-06（X 主页显示约 7 小时前，Prime Intellect 博客同日确认 "Today, we are launching Prime Agent"）

**Summary**：Prime Intellect 开源发布 Prime Agent，一个基于 Recursive Language Model（RLM）与 Continual Harness 的自改进编程 Agent 框架。它把上下文当作变量、把子 Agent 调用当作 REPL 里的函数调用，通过持久化 IPython 内核实现可编程的工具调用、多 Agent 消息与可自我修改的 Harness 状态。在 ARC-AGI-3 上，Prime Agent + Opus 5 达到 95.5%（Best@1），超过 ARC 报告的人类专家基线 95.4%；Best@3 达到 99.97%，183/183 关卡全部完成。此外，在 EmulatorBench 上它可从零用 Rust 写出 SEGA Genesis 与 Game Boy Color 模拟器并通过对角测试。

**Key Points**:
- Agent 能力：持久化 IPython 内核作为唯一工具，支持程序化工具调用、并行子 Agent fan-out、Agent-to-Agent 消息。
- 模型突破：ARC-AGI-3 95.5%  surpasses 人类专家基线；子 Agent 可跨会话持久化并被后续消息唤醒。
- 效率进展：通过函数式数据操作减少 Token 消耗；Compact/Refine 机制在线管理上下文与 Harness 状态。
- 开源：基于 pi 构建，完全开源，可 `curl` 一键安装。
