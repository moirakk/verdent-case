### Revision Notes (2026-08-24, v2)

First pass (CRT/terminal style, mint-on-black, workflow-node diagram) tested fine
technically but didn't have the pull the reference examples had. Rebuilt as an
editorial letterbox look:

- Reference: Anthropic/OpenAI-style TikTok clips — sans/serif headline on solid
  color blocks, smooth crossfades, letterboxed 9:16.
- Palette moved to an all-green family (sage/moss/mint-white/deep-green) instead
  of CRT mint-on-black.
- Logo redrawn from the real Verdent mark (flame/leaf silhouette, single flat
  fill) instead of a hand-built gradient approximation.
- Motion redesigned per `skillbook/visual-system.md` -> Motion: distinct entrance
  per scene type, continuous camera drift, accelerating reveal cadence, exactly
  one loud beat (artifact-reveal flash + bounce) instead of uniform motion
  throughout — this was the fix for the "static/lifeless" feedback on the first
  editorial pass.
- See `skillbook/visual-system.md` for the full ruleset this now follows.
