# Cases

`cases/` stores planning notes, recording status, publishing links, and retrospectives.

The actual editable HTML video files live in:

```text
episodes/
```

## Current Case

```text
cases/2026-08-24-skillbook-episode-001-plan-mode/
```

Primary episode file:

```text
episodes/ep-001-plan-mode.html
```

## Case Folder Shape

```text
cases/YYYY-MM-DD-topic/
└── README.md
```

Add `assets/` only when a case has local images, screenshots, or video-specific media.

## README Should Record

- brief
- skill being demonstrated
- input -> skill -> artifact transformation
- shot plan
- recording-ready commit
- publish links
- retrospective
