# Templates

This folder is intentionally minimal.

The current reusable source of truth is:

```text
episodes/ep-001-plan-mode.html
```

For the next episode, duplicate that file into `episodes/ep-002-*.html`, then replace:

- case tag
- skill name
- messy input
- process fields
- artifact reveal
- before / after / next

Do not reuse the retired CRT templates. The current Skillbook system is the editorial green letterbox direction documented in:

```text
skillbook/visual-system.md
skillbook/video-system.md
```
